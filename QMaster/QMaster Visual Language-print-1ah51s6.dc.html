QMASTER · VISUAL LANGUAGE

Instrument — a precision readout for the work of testing.

QMaster is a calm graphite instrument, not a marketing surface. The chassis stays quiet so the signal can be loud: every bit of color earns its place by communicating state, priority and ownership — never decoration. No purple gloss, no gradient headings, no shouting hero metric.

paletteThe color strategy

A control room at night. The room (neutrals) is a cool blue-grey graphite — explicitly not cream. One confident cobalt is the instrument's light: it marks what's actionable and what's selected, nothing else. State lives in a disciplined signal set — green pass, red fail, amber blocked, steel info, neutral skipped — tuned for both themes.

sensorsThe signal set
{{ s.icon }}{{ s.label }}
Constraints honored: OKLCH tokens · light + dark · 1rem = 14px · AA body contrast · never color-alone (icon + shape + label) · focus rings · ≥44px touch targets.
layers
Built on the S9 Headless UI system. Every component, the buttons, badges, inputs, avatars and tables below, is a real S9 component. Instrument doesn't fork them — it re-tunes the foundation: my OKLCH ramps override S9's color ramps, so S9's own semantic tokens and dark-mode machinery resolve to the graphite-and-cobalt palette automatically. The QA signal set (passed/failed/blocked/skipped/invalid/untested) is the product-specific layer added on top.
